Research

Waterloo Computational Learning (WatCL) Lab Sep 2026 – present

Researcher, supervised by Prof. Kimon Fountoulakis

I build tools that index mathematical claims and their dependencies and link planned Lean declarations to the source text. I tested those tools on Vershynin’s High-Dimensional Probability and ran self-hosted Leanstral and DeepSeek experiments to study where generated statements diverge from the source and where proof generation fails.

DIT AI Team, NKUA Apr 2024 – Jun 2026

Undergraduate researcher, advised by Prof. Manolis Koubarakis and Sergios Kefalidis

For my BSc thesis, SPHINX: A Configurable Framework for Generating Synthetic KGQA Benchmarks, I extended KGQAGen beyond Wikidata so it could generate synthetic questions and SPARQL queries for other knowledge graphs. I evaluated the framework across three graphs.

I also assisted Sergios Kefalidis with experiments and evaluation for his PhD research on knowledge graph question answering.

Projects

  • Response Clarity Classification Jupyter

    For a course project at NKUA, I compared several ways to tell whether a politician answered the question they were asked. On the same test set, a prompted model scored 0.69 macro F1 and a fine-tuned encoder scored 0.68. In a separate experiment, four agents performed worse than a single call to the same model.

  • Adaptive Dictionary Compression for String Columns C++14

    A from-scratch implementation of the adaptive dictionary compression scheme in Foufoulas et al., Adaptive Compression for Fast Scans on String Columns (SIGMOD '21): pages alternate between self-contained and differential dictionaries, so a string column stores like a global dictionary but scans like a local one. Benchmarked against DuckDB over Parquet — up to 45× compression on repetitive columns, and filtered scans about 10× faster on high-cardinality ones.

  • File Synchronization System C

    A Linux file sync daemon: inotify watches, forked workers, a named-pipe CLI and a Bash status script.

  • Heap File and External Merge Sort C

    An external merge sort over a heap file built on a block-based buffer manager, for sorting data that does not fit in memory. I implemented the b-way merge component, which combines sorted runs across successive passes, for this team databases assignment at NKUA.
