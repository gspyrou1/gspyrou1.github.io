Research

My work sits between the theory of learning and the systems built on top of it: machine learning and its mathematical foundations, knowledge graph question answering, and synthetic data generation for training and evaluating those systems.

SPHINX: A Configurable Framework for Generating Synthetic KGQA Benchmarks 2026

BSc thesis, supervised by Prof. Manolis Koubarakis and Sergios Kefalidis (PhD candidate)

A framework for generating synthetic KGQA benchmarks with large language models. It builds on KGQAGen, removing that system's Wikidata-specific design so it can generate datasets over any knowledge graph, then addresses four weaknesses of the original: fragile grounding on strongly typed stores, shallow or vague questions, heavy resource consumption, and the absence of complex SPARQL operators in generated queries. Evaluated across three knowledge graphs.

Projects

  • file-sync-system C

    A Linux file sync daemon: inotify watches, forked workers, a named-pipe CLI and a Bash status script.

  • adaptive_compression_implementation C++14

    A from-scratch implementation of the adaptive dictionary compression scheme in Foufoulas et al., Adaptive Compression for Fast Scans on String Columns (SIGMOD '21): pages alternate between self-contained and differential dictionaries, so a string column stores like a global dictionary but scans like a local one. Benchmarked against DuckDB over Parquet — up to 45× compression on repetitive columns, and filtered scans about 10× faster on high-cardinality ones.
